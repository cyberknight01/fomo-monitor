<h1 align="center">FOMO Monitor</h1>

<p align="center">你的持仓、关注的 KOL、重要变化，一处查看。</p>
<p align="center"><strong>V0.1</strong> · Chrome 扩展 · 中英双语 · Telegram 告警</p>

FOMO Monitor 是面向 [FOMO](https://fomo.family) 用户的持仓观察工具。通过后台 API 轮询，汇总当前持仓与关注者动态，在发生买入、加仓、减仓、清仓或市值越线时发送 Telegram 提醒，减少来回查看页面的操作。

> 本项目是独立开发的第三方工具，与 FOMO 官方无隶属关系。不执行自动交易。

## 能做什么

| 功能 | 说明 |
| --- | --- |
| 💼 持仓总览 | 查看非现金持仓总价值、逐币市值、持仓金额与未实现盈亏 |
| 👥 KOL 观察 | 展示头像、持仓价值及盈亏；点击名称直达对应 FOMO Profile |
| 🔎 三类筛选 | 前 10 大持仓、返回样本内最低建仓市值 10 人、我关注的 KOL |
| 🔔 行为提醒 | 首次买入、加仓、减仓、清仓使用不同彩色标识与加粗标题 |
| 🎯 逐币市值规则 | 上涨、下跌独立分档，支持百分比、倍数与目标市值，支持 K / M / B 输入 |
| ✅ 告警开关 | 每币独立控制，也可一键全选或全部取消 |
| 🪟 独立窗口 | 默认居中，可拖动边缘调整大小；折叠卡片、固定顶栏、记住窗口尺寸 |
| ⏱ 刷新状态 | 显示市值与 KOL 刷新倒计时，以及暂停、同步、检查中等状态 |
| 🌐 中英双语 | 首页和设置页一键切换，保存语言偏好 |
| 🧾 操作记录 | 在对应 KOL 下展开查看本插件已记录的最近变化 |

**排名范围说明：**“最低建仓市值”仅在接口已返回的持仓者样本中排序，不是全平台最低买入排名；“前 10 大持仓”来自 FOMO 返回的排行，也不代表链上全部钱包。

## 安装

需要 **Chrome 120 或更新版本**、可登录的 FOMO 账户。Telegram 提醒另需自己的机器人。

1. 下载项目源码 ZIP，或克隆仓库，并解压到固定目录。
2. 在 Chrome 地址栏输入 `chrome://extensions/`。
3. 开启右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的目录。
5. 将 FOMO Monitor 固定到工具栏，点击图标打开监控窗口。

无需构建；ZIP 文件本身不能直接加载。当前安装方式为加载源码目录。

### 升级并保留配置

备份原目录，将新版文件覆盖到**原来已加载的目录**，然后在扩展管理页点击「重新加载」。关闭旧监控窗口，再点击插件图标打开新版。

不要卸载旧扩展。加载到不同目录可能产生不同扩展 ID，原 Telegram 和监控设置可能不会自动共享。

## 首次配置

### 1. 同步 FOMO

1. 点击齿轮进入设置，输入自己的 FOMO 名称并保存。
2. 手动刷新已登录的 FOMO 页面，等待页面完成加载。
3. 返回插件，确认已同步的账户与监控账户一致。
4. 点击刷新，核对持仓数据，再开启后台定时监控。

同步完成后，可以关闭 FOMO 标签页。监控请求由扩展后台发出，不会自动打开或扫描 Profile / Token 页面。

### 2. 连接 Telegram

1. 在 Telegram 通过 **@BotFather** 创建机器人，取得 Bot Token。
2. 向自己的机器人发送 `/start`，并准备接收消息的 Chat ID。
3. 在插件设置中填写 Bot Token、Chat ID，点击「保存后测试 Telegram」。
4. 收到测试消息后，开启 Telegram 总开关及所需的告警类别。

Bot Token 是凭证，请勿放进公开仓库、Issue 或截图。

### 3. 设置逐币提醒

每个 Token 可设置独立的告警总开关和市值规则。总开关勾选后自动保存；阈值编辑完成后需点击「保存该 Token」。

假设基准建仓市值为 **1M USD**：

| 设置方式 | 输入 | 目标市值 |
| --- | --- | --- |
| 上涨百分比 | 100% | 2M |
| 下跌百分比 | 20% | 800K |
| 基准倍数 | 3× | 3M |
| 目标市值 | 1.5M | 1.5M |

默认基准按平均买入价换算建仓市值，属于估算值。缺少买入价时需手动填写；市值倍数不等同于个人收益倍数。

- 首次读取或保存新规则只建立基线，不补发历史越线。
- 每个方向、每个档位提醒一次；需要再次监控同一档位时可「重新布防」。
- 关闭单币告警会清理该币的待发消息；已经发送或正在发送的消息无法撤回。
- 全部取消也适用于后续新增持仓，之后仍可单独启用某个 Token。
- 所有规则只发送提醒，不执行买卖。

## 刷新与倒计时

市值检查覆盖当前持仓；KOL 详情按配置周期分批更新。可选择均衡、更及时、省资源或自定义方案。

顶栏倒计时根据后台调度状态计算。**KOL 倒计时指下一次可开始检查的批次，不代表全部 KOL 都将在该时刻更新完成。** 网络延迟、限流、浏览器调度或电脑休眠都可能推迟实际检查。

暂停、未同步会话、限流或正在检查时，界面会显示对应状态，避免把未执行的刷新显示为已完成。

## 数据范围与已知限制

- 使用 FOMO 的非官方接口，接口结构、认证与可用性可能改变。账户需与同步会话匹配。
- KOL 指平台返回的持仓者或你关注的账户，不构成对其投资能力的认证。排行筛选只改变展示，不扩大原有 TG 告警范围。
- 关注者列表和成交首屏可能被截断；本插件的操作记录不是完整交易历史，轮询之间的短暂变化可能漏报。
- 买卖提醒根据快照间的累计成交变化判断，可能包含多笔交易；持仓者从列表中消失，不会单独作为清仓依据。
- 平均建仓市值按平均买入价与当前隐含供应量估算；盈亏口径见界面说明，不应视为精确历史成本或最终可兑现收益。
- Chrome 退出、电脑休眠或登录会话失效时，后台监控不能持续工作。浏览器重启或会话过期后需重新同步。
- Telegram 发送失败会重试；网络异常时可能延迟或重复，不能保证每条提醒恰好送达一次。
- **AI 投资逻辑分析尚未开放。** 当前按钮仅为规划功能占位。

详细请求字段与数据边界见 [接口说明](接口说明.md)，验证记录见 [验收记录](验收记录.md)。

## 隐私与权限

| 数据 / 权限 | 用途 |
| --- | --- |
| `storage` | 保存本机设置、快照、告警队列和日志 |
| `alarms` | 调度后台检查 |
| FOMO 域名访问 | 同步登录会话、请求持仓及交易数据 |
| Telegram API 访问 | 向你配置的 Chat ID 发送提醒 |

FOMO 会话凭证保存在浏览器会话存储中；Telegram Bot Token 保存在本机扩展存储中。插件不要求钱包私钥或助记词，不增加独立的开发者数据接收服务器。头像会从 FOMO 返回的图片地址加载。

调试导出不含 Bot Token、Cookie 或会话令牌，但仍可能包含账户与持仓信息。提交反馈前请自行检查并删除不希望公开的内容。

## V0.1 刷新倒计时与 TG 样式

首页顶栏显示市值及 KOL 倒计时。时间来自 Chrome alarm 的 scheduledTime；KOL 会根据每币最近更新时间和最短检查间隔，计算下一批符合条件的检查时间，并非全部币完成时间。浏览器调度、网络耗时与休眠可能延后；倒计时到零后显示等待执行，不伪造新一轮倒计时。定时器只更新界面，每 10 秒读取一次本地状态，不新增 FOMO 轮询。

TG 操作标题使用彩色 Emoji + bold entity。所有账户名与代币名保持普通文本，不作为 HTML 执行。格式依据：[Telegram Bot API formatting](https://core.telegram.org/bots/api#formatting-options)。
