FOMO Monitor · V0.1

后台直接读取 API · 无页面扫描或自动打开标签页

1 · 同步 FOMO 会话

安装后，手动刷新已登录的 FOMO Profile，等待页面完成加载，再点「刷新显示」。同步后可以关闭 FOMO 标签页。

仅观察官网请求中的登录令牌和当前用户 ID，不扫描仓位或页面。令牌只保存到浏览器会话内存；浏览器重启或令牌过期后需再次手动刷新。不会自动登录或续期。

手动令牌备用方式

仅在自动同步失败时使用。必须确认此令牌属于下方填写的 Profile；此方式无法独立验证令牌所有者。不要粘贴钱包私钥或助记词。

2 · 监控设置

高级性能设置

每次市值检查覆盖全部当前持仓；KOL 分批轮询。网络繁忙时延后，不堆积检查任务。Chrome 退出或电脑休眠时暂停。

3 · Telegram

先在 Telegram 中向自己的机器人发送 /start。Bot Token 保存于本机 Chrome 扩展存储，不会写入调试导出。测试按钮会发送一条消息。

每个 Token 的市值提醒

默认基准按平均买入价换算建仓市值（估算），可输入 K / M / B。上涨和下跌独立设置，支持涨跌幅、倍数或目标市值。

保存时建立基线，之后按设定方向越线提醒。每档一次，可重新布防；这些规则只发通知，不执行卖出。

调试日志

包含接口路径、状态码、耗时和异常。不包含令牌、Cookie 或完整响应。导出仍含用户名与持仓信息。

此版本基于 2026-09-06 官网实际请求。非官方 API 可能变化；列表与成交记录均来自 FOMO，不能保证覆盖平台外交易。详见项目 README 和接口说明。
